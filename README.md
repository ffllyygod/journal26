# Journal26

A private daily journal for a 60-day challenge: plan the day ahead, check in on habits, journal trades, track the job search, and review each week. Next.js and Supabase, built for phone and laptop.

- **Run it:** `docs/SETUP.md`
- **Status, decisions and what is left:** `docs/PROJECT_STATUS.md`
- **Checks:** `npm run check`, `npm run test:e2e`, `npm run test:cloud`

No account needed to try it: without Supabase configured, `npm run dev` serves a sample workspace at `/demo`.
